# Fix login and password issues

1. Use the same email you registered with (check spam for the original invite).
2. Click Forgot password on the login page and open the reset link within 30 minutes.
3. Choose a new password with at least 10 characters.
4. If SSO is enabled for your org, use “Continue with company SSO” instead of password login.
5. Still blocked? Ask a workspace admin to re-invite you from Settings → Members.
