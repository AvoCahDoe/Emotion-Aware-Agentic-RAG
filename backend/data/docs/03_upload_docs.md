# How to upload documentation

1. Open your workspace and choose Documents.
2. Click Upload and select Markdown (.md) or plain text (.txt) files up to 2 MB each.
3. Wait for the green “Indexed” badge — indexing usually finishes in under a minute.
4. Test with Ask: try a question that only your new file can answer.
5. If indexing fails, re-save the file as UTF-8 and upload again.
